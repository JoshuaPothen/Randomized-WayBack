# Randomized-WayBack

"The Wayback Dispatch" — a Next.js/TypeScript app that assembles a randomized "front page" of archived personal/hobby web pages pulled from the Internet Archive's Wayback Machine. See `wayback-dispatch-prd.md` for the full product spec.

## Running locally

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm test        # run the test suite
npm run build   # build for production
```
